# 框架示例依赖许可

2026-09-08 核对四个独立环境的锁文件与发行包 METADATA；未在 Windows 安装的条件依赖按同版本 PyPI 元数据核对。97 个包身份及许可记录在 license-policy.json，由 npm run licenses:check 对照全部锁文件验证。

此仓库只提交自己的示例和依赖锁，不复制第三方源码或二进制。uv 安装保留发行包的许可文件；MIT、BSD、Apache 等通知继续适用。MIT-CMU、MIT-0 同样保留原发行许可。MPL-2.0 及复合表达式没有被简化成 MIT；若以后修改或分发对应文件，需满足 MPL 源文件和通知义务，AND 表达式中的义务同时适用。

更新锁文件后重新读取目标发行元数据和必要许可文件，再更新记录。缺失或不认识的许可阻止采用，不通过临时忽略恢复绿色。此核对不证明供应链没有漏洞。
