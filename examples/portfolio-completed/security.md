# 安全记录：限定本地教学范围

资产为预审源码、固定业务测试、配置身份与公开结果。威胁来源包括错误完成文本、意外路径修改、损坏回执和错误证据标签。

| 威胁 | 控制 | 证据 | 残余风险 |
| --- | --- | --- | --- |
| 假完成 | 独立重读并执行测试 | baseline 的完成提议遭拒绝；假完成单测 | 任务测试未覆盖的业务行为仍未知 |
| 越界或额外文件 | 固定工具参数、git diff、未跟踪文件检查 | 损坏工作区负例 | 不是运行任意代码的通用沙箱 |
| 篡改验证器 | 原始字节 hash 与预审版本比较 | verifier 损坏负例 | 预审输入自身仍需可信来源 |
| 替换产物 | 文件引用、hash、身份与实际终态一致性 | check-study 的坏产物负例 | hash 不能证明作者可信或 holdout 没被人查看 |
| 错把 E1 当 E2 | 学习研究阻断；离线 Run 不准升级标签 | E2 重标负例 | 研究代表性仍需人工评审 |
| 泄露私密信息 | 合成数据、相对路径与公开扫描 | results:redact、secrets:check | 扫描不能替代人工阅读 |

当前范围没有网络工具、真实模型凭据或远端写入。即使固定 Python 源码被实际执行，也不能将任意模型源码放进此执行器。若需要扩大范围，重新设计隔离和授权。

发现异常时停止后续步骤，保留最小失败证据。临时资源只清理本次创建的目录；报告继续保存。回退配置后用新的输出目录复测，旧失败记录不改写。
