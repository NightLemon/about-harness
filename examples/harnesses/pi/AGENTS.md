# Example project instructions

## Scope

Inspect before editing and keep changes inside this example project.

## Boundaries

- Do not access network services, credentials, remotes, or paths outside the project.
- Do not install packages or load project extensions for this exercise.
- Stop when a command or setting differs from the pinned Pi documentation.

## Verification

Use deterministic local checks. Report changed files, exit codes, failed assertions, and the rollback point.
