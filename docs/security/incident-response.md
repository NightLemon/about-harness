# Agent 事件响应

## 触发条件

Secret/个人数据泄漏、未授权副作用、破坏性写入、供应链异常、费用失控、跨租户访问、公开 artifact 污染或无法解释的权限提升。

## 顺序

1. 停止 run/子任务/部署，禁止自动重试；
2. 隔离 artifact 与本地/远程环境，不扩大读取；
3. 撤销凭据、token、session 和有风险访问；
4. 保存不含秘密的时间线、版本、trace hash 和受影响范围；
5. 恢复到已知良好 checkpoint/release；
6. 修复根因与防回归；
7. 按责任人确认后恢复自动化。

## Git 与发布

删除工作树文件不等于清除历史；一旦 push，历史重写、通知和凭据轮换需要专门授权。未授权时只隔离并报告。

## 复盘

记录 detection gap、为什么 control 没阻断、受影响数据/人、恢复时间和 residual risk。复盘不包含可复用 secret 或攻击载荷原文。
