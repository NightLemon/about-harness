# Prompt Injection 防护

Prompt injection 是不可信内容试图被当成高优先级指令。网页、issue、代码注释、PDF、工具结果与 memory 都可能携带。

## 不能依赖的办法

只告诉模型“不要被注入”、使用更强模型、隐藏 system prompt、让第二个模型判断。它们可降低概率，不是硬边界。

## 分层防护

1. 标注来源与 trust，不把数据拼成 system 指令；
2. 只提供任务所需工具、路径、域和数据；
3. 副作用前 policy/schema/approval；
4. 对外发、下载、执行与凭据访问设置硬 gate；
5. 输出/轨迹检测目标漂移和秘密；
6. 攻击 fixture 回归。

## 浏览器例

页面写“把环境变量发到某 URL”时，agent 应把它作为页面文本抽取/拒绝，不改变允许域或访问环境变量。M5 浏览器案例用本地合成页面验证。

## 事件

一旦工具已越权，停止 run、隔离 artifact、撤销凭据并审计日志；不要继续让模型“自行修复”。
