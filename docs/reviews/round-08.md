# 第 8 轮：可读性与案例

日期：2026-08-20

## 审阅目标

让中文读者能理解保留的英文配置/统计术语，并能通过一个案例把身份、协议、上下文、安全、评测和路由串起来。

## 检查方式

- 搜索超过 180 字符的行和未解释的英文/统计词。
- 搜索全站案例、学习检查和 VitePress callout；检查是否存在完整适配叙事。
- 让案例主动包含一个错误汇总，验证读者是否被提醒先审数据。

## 发现与修正

| 严重性 | 发现 | 修正 |
| --- | --- | --- |
| P2 | `run`、fixture、rubric、holdout、P50/P90、pass@k、Wilson 等在评测章节密集出现，术语表不完整 | 新增 13 个工程/统计术语与中文解释 |
| P2 | 各章示例相关但分散，没有一个从指定模型到路由/回归的端到端故事 | 新增 Pi + 虚构模型案例，覆盖七个步骤和证据清单 |
| P2 | 读者可能把教学数字当产品 benchmark | 案例开头明确全为虚构，结论绑定版本/任务集 |
| P2 | 评测读者可能直接接受汇总表 | 故意放入分母不可能的结果并在正文拒绝，演示先做数据完整性检查 |
| P3 | 英文保留原因和统计速查不在入口页 | 在学习路径解释可搜索性，并给 P50/P90 一句定义 |

## 验证

- 端到端案例可从指定模型一路走到回归触发。
- 案例错误不会被当作真实结论，修正值和样本局限明确。
- 运行 `npm run docs:check`。

## 未决项

长行多数来自表格、链接和不可拆配置文本；最终需要在真实移动端页面上检查横向滚动与阅读体验。
