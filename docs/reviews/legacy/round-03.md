# 第 3 轮：事实与来源

日期：2026-08-20

## 审阅目标

区分官方产品事实、本项目建议和教学示例；让易变事实可追溯，并避免滚动主分支破坏复现。

## 检查方式

- 搜索三份 harness 指南中的“当前、默认、支持、不内建”和命令。
- 检查产品页是否有核对日期、官方来源和可用性限定。
- 用 `git ls-remote` 检查 Pi 主分支的漂移，核对浏览时页面显示的目录 commit。

## 发现与修正

| 严重性 | 发现 | 修正 |
| --- | --- | --- |
| P1 | Pi 只链接 `main`，访问期间主分支已经移动，无法复现核对内容 | 增加实际核对的完整 commit 链接，同时保留当前主分支入口 |
| P2 | 三个产品页把官方事实和作者调优建议连续书写，读者可能误认成厂商承诺 | 每页增加“事实基线与本文建议”说明，并给关键事实内联引用 |
| P2 | 横向比较表虽有总来源页，但没有说明表后选择建议的证据性质 | 增加表格事实/项目建议边界与可用性限定 |
| P3 | 来源页没有统一定义引用纪律 | 新增事实、原理、建议、示例四类证据表 |

## 验证
