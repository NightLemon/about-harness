# 第 2 轮：信息架构

日期：2026-08-20

## 审阅目标

确认新手、指定模型优化者和 harness 迁移者能从首页/侧栏走到一个明确产物，并让知识地图承担导航而不只是概念展示。

## 检查方式

- 对照 `docs/.vitepress/config.mts` 的导航与全部 Markdown 文件。
- 搜索正文中的“开始、路线、下一步、完成、学习检查”。
- 从三类读者目标模拟点击路径。

## 发现与修正

| 严重性 | 发现 | 修正 |
| --- | --- | --- |
| P2 | 路线只列阅读页面，没有说明实践投入和最终产物 | 新增“目标—建议投入—产物”入口表 |
| P2 | 新手路线跳过“指令与扩展”和实验设计，读者会从安全直接跳到实验室 | 补齐指令、提示契约与实验方法，形成原理→配置→实验闭环 |
| P2 | 七层知识地图的机制名称不可点击，无法作为分流入口 | 将每一层链接到对应核心页面，并增加七层自画像练习 |
| P3 | 稳定原理、易变产品事实和可复制实践没有视觉/阅读提示 | 在学习路径增加三类页面的阅读标记 |

## 验证

- 三条路线都能从 `/guide/start` 到达明确产物。
- 侧栏覆盖全部正式正文；review 记录通过迭代记录页访问。
- 运行 `npm run docs:check`。

## 未决项

尚未做真实用户可用性测试。后续可让首次接触 coding agent 的读者完成“画七层图”任务，并记录找页时间与误解点。
