# 浏览器 Agent 模式

## 三个信任域

用户/系统指令、页面内容、浏览器动作必须分离。网页文字是不可信数据，即使写着“忽略之前要求”也不能提升为指令。

## Harness 重点

允许域名/路径、浏览器 profile 隔离、下载限制、表单/支付/发送前批准、可见 UI 状态、selector fallback、截图与 DOM artifact、timeout 和清理。

## 失败模式

Prompt injection、广告/隐藏元素、登录态泄漏、误点副作用、页面漂移、无限分页、验证码、下载恶意文件、把截图视觉相似当业务正确。

## 指标

结构化字段正确率、步骤/重试、页面漂移恢复、注入拒绝、未经批准副作用为零、截图/DOM 可复现。M5 只操作本地合成站点，无外网与真实账号。
