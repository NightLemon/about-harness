# 记忆优化

## 先定义失败

记忆优化不是“记得更多”，而是减少重复输入，同时不增加错误检索、过时规则或隐私风险。先量化：检索命中、错误记忆引用、token、人工纠正和删除完成时间。

## 实验变量

写入 gate、chunk/record 粒度、scope、TTL、可信来源过滤、top-k、reranker、摘要格式与失效触发。每次只改一个主要变量，固定任务和其他上下文。

## 基线

Baseline A 无长期记忆；Baseline B 只使用人工维护项目指令；候选才启用自动写入/检索。若候选只在训练任务提升而 holdout 下降，说明过拟合或污染。

## 安全门禁

敏感字段不写入；不可信页面不自动持久化；用户可列出/删除；版本变化会失效；公开 trace 不包含原文。任何泄漏或错误权限检索直接否决候选。
