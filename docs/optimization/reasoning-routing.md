# 推理预算与模型路由优化

## 路由输入

任务类型/规模、风险、所需工具、多模态、上下文、延迟 SLO、费用上限和过去失败类型。不要按“这个模型总体更聪明”路由。

## 三档示例

- Fast path：局部、确定性、强验证；
- Standard：常规多文件/多步骤；
- Escalation：跨系统、高歧义或 baseline 多次失败。

档位只是项目建议，必须映射到目标 provider 的实际模型与预算设置。

## 晋级规则

预注册主指标的实际改善阈值，成功区间不支持明显退化，安全无回退，成本和 P90 延迟在预算内。只在失败后升级会造成 selection bias；正式比较对相同任务运行所有候选。

## 回退

协议不兼容、tool error、预算耗尽、timeout、模型不可用与安全拒绝分别路由；不要用无限重试或自动扩大权限恢复。
