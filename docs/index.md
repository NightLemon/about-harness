## 从眼前的问题进入

Agent Harness（智能体运行与控制系统）连接任务、模型和工具，并管理权限、状态、预算与验收。

| --- | --- | --- |
| 定位 Agent 生态中的职责 | [生态全景](/ecosystem/overview) | 分层责任图与选择入口 |
| 练习能力与编排边界 | [生态工作坊](/practice/ecosystem-workshop) | 三类 E1 合成实验与失败断言 |
| 准备工程面试材料 | [五张迁移卡](/guide/interview-practice) | 可复现证据与项目深挖记录 |

| 亲手跑通完整流程 | [端到端案例](/practice/end-to-end) | 实际补丁、测试、轨迹与报告 |
| 选择或适配模型 | [模型适配与选择](/models/adaptation) | 资格测试和采用依据 |

## 学习成果

主线围绕同一个任务形成六项产物：知识地图、最小 Harness、模型适配卡、配对研究、安全评审和迁移记录。[学习路径](/guide/start)给出先后顺序，[知识地图](/guide/roadmap)展示概念依赖。

本站默认实验是 E1 离线证据；实际框架运行与真实模型质量分开评价。产品事实的来源和日期见[事实注册表](/references/fact-registry)，E0–E3 的具体含义见[证据等级](/evaluation/method#e0e3-到底增加了什么)。
